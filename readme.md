> 由小旭个人开发制作，仅供个人测试交流使用。

#### 它能做什么

- **磁盘清理**：5 大类共 76 个清理项（清理库 76 条规则全部有效：系统 35 / 应用 23 / 浏览器 9 / 显卡 5 / 特殊 4），扫描后按风险等级与可释放空间勾选执行；明细可先预览再删，释放空间按删除前后实际差值统计。
- **内存清理**：按 6 个区域勾选释放内存，含「顽固软件专杀」；调用 Windows 系统接口，与 Mem Reduct 同款原理。
- **电脑优化中心**：12 个分组共 125 个优化项（SSD 通常可见 122 项），单项执行或勾选一批执行；每项都有详情弹窗、风险等级、预期效果与**可核对的还原入口**。优化项里仍有含 pwsh 步骤的 37 项 / 42 步走系统 PowerShell，其余全部由 Rust 原生引擎执行。
- **启动项管理**：扫描注册表 / 启动文件夹 / 计划任务，启停与系统「任务管理器」同轨（随时可逆），删除前自动备份。注册表里写着的路径已经不存在时，该项标为「待确认」并原样显示那个路径，出口是查看详情、删除启动项、打开系统自带的 Windows 安全中心 —— 只报事实，不替你判定它是不是恶意。
- **右键菜单管理**：按 15 类扫描，但**按软件成列** —— 一列一个程序，列头是它的真实图标与「N 项 · M 个位置」，位置与状态标签直接跟在名称后。归属由程序文件的版本信息判定，靠推断得来的会标注依据，判不出的集中到「未识别」列而不是硬猜一个名字；勾选即启用、取消即禁用，可切换 Win11 经典/新版形态、查看 Shell 扩展屏蔽表。
- **应用卸载与残留**：调起原厂卸载器（静默命令由后端准入闸裁决，不信任界面回传的命令文本）；卸载后可扫残留 —— 规则库命中、失效项、应用数据遗留三类分别给依据。文件与目录**回收站优先**（失败不改成永久删除），注册表先 `export` 备份再删、备份失败该项不动。另有独立的**「残留扫描」窗口**：七个深扫器报告服务、驱动、minifilter、IFEO、厂商键、能力授权与游戏库目录。发现绝大多数只说明依据；能删的只有两个窄口子——已卸载应用遗留的游戏库目录（移入回收站，可还原）和过八道现读判据（落点已失踪、非内核驱动、无依赖声明等）的失效服务键（先整键导出 .reg 备份再删）。受保护与未过判据的一律只说明为什么，勾选后仍要逐项确认。
- **系统维护**：SFC / DISM / Windows 更新组件重置 / 音频服务 / 搜索索引 / DNS 刷新 / 网络栈重置等维护任务；另有**电源计划三档切换**与**虚拟内存读写**（写前自动备份）。
- **运行库修复**：检测 VC++ / .NET Framework / DirectX 安装状态，缺失时经微软官方直链（SHA-256 校验）补装。
- **磁盘 / 网络测速**：磁盘测速为原生 OVERLAPPED 异步 I/O，块大小、队列深度、线程数、时长均可调；网络测速走 SpeedTest.cn 或中国科大节点。
- **网络检测**：6 项只读诊断（网卡 / IP / DHCP / DNS / 代理 / 连通性），异常项给证据与修复建议。
- **实时网速**：常驻显示上下行速度与丢包率，可录制并生成折线图报告。
- **外设调优**：处理器调度、鼠标事件缓冲两组深度调优，每档配「数值解释」说明这个数到底控制什么。键盘队列深度与端口路由已并入「优化中心」的键盘项统一管理。
- **系统还原点**：查看各磁盘保护状态，一键为所有已开启保护的磁盘创建还原点。
- **备份还原**：各类注册表 / 文件备份统一管理，值级回读校验后才算还原成功。
- **联网 AI 简介**：启动项 / 右键 / 内存清理的条目详情可主动获取 AI 简介（可选，不联网时用内置本地简介）。

## 安装

在 [Releases](../../releases) 下载 `Trim_<版本>_x64-setup.exe` 双击安装，或下载 `Trim_<版本>_x64-portable.zip` 解压后直接运行 `Trim.exe`。

- **安装版**：桌面快捷方式 + 卸载项，更新走应用内「检查更新」。
- **便携版**：解压到有写入权限的目录即可，不创建快捷方式与卸载项；升级时先退出旧进程再覆盖解压。

> 便携版默认使用 `%APPDATA%` 下的数据目录。在 `Trim.exe` 同目录新建空文件 `Trim.portable` 可切换为便携模式（数据改存程序目录的 `data` 子文件夹），删除该标记文件即恢复。

系统要求 Windows 11。多数功能需要**管理员权限**（写 HKLM、改服务），未提权时界面会明确提示，可回主窗口以管理员身份重启。

## 使用

### 优化项怎么改

点任意优化项弹出详情窗，里面有：执行步骤、风险等级、预期效果、优缺点、可还原入口。确认后点 **立即执行**。

- **已优化的项**整行灰态，点击可还原。本机有值级备份的按备份逐值还原，没有的置灰并说明原因 —— 不会给一个点了必然失败的按钮。
- **批量执行**前会整批预检（权限 / 高危确认 / 本机可执行性），被拦项先告知再执行，不会「第 5 项失败时前 4 项已落盘」。
- **写后回读**：执行与还原都会重新读注册表核对，不符即如实报错并保留备份（fail-closed）。
- 125 个优化项按 12 个分组显示，125 项里有 14 项高风险，其中 **9 项执行后无自动还原**（其余 5 项支持一键还原）。凡是动服务、驱动、注册表、启动参数的，**先建系统还原点**。

### 删除类操作

- 除「常规清理项」固定永久删之外，一律**回收站优先**，且删除前过受保护目录校验；
- 右键项 / 启动项删除前自动备份注册表项，文件类条目（「发送到」、Win+X 的 .lnk）走回收站；
- 高危操作弹红色二次确认，确认框里写明具体后果与影响范围。

### 原理

```
┌──────────────┐   IPC 通道白名单    ┌─────────────────────┐
│  渲染进程     │ ──────────────────> │  Rust 命令层         │
│  零框架       │ <────────────────── │  guard 来源校验       │
│  原生 HTML/CSS │   JSON 回执         │  白名单 / 取值校验    │
└──────────────┘                     └──────────┬──────────┘
                                                 │
                        ┌────────────────────────┼────────────────────────┐
                        ▼                        ▼                        ▼
              Win32 / WinHTTP 原生        reg.exe / 签名规则库        应用私有数据目录
              （服务 / 注册表 / HTTP）      （备份 / 装载前验签）      （配置 / 备份 / 日志）
```

- **执行前先记账**：写不进状态文件就不改系统（fail-closed）。
- **每条命令都有来源校验**：主窗专属通道与只读通道分档，多窗口应用不允许裸注册命令。
- **规则库与优化目录随版本交付并签名**，装载前验签；没有「后台定时热替换规则」这种入口。
- **数据留在本机**：配置、日志、备份全在 `%APPDATA%\<标识符>`，便携模式改存程序目录。

## 不做的事

Trim 的原则：**说不清收益的改动，宁可不做**。以下常见「优化技巧」经实测或公开机制分析后刻意不提供：

- **清空整个待机列表「释放内存」**：待机列表本就计入可用内存，清空丢掉的是热缓存。
- **修改启动配置数据（BCD）类「玄学参数」**：无论计时器合并、动态时钟，还是关开机动画、关启动调试、改超时等待，机制上都属启动配置改动而非性能优化，收益不可测且失误会影响开机。Trim **完全不读写 BCD**，这类改动一律不提供。
- **MMCSS 给游戏提优先级**：实测无可测收益，不提供。**边界说明：音频任务调度**的两项不在本条范围内，仍作为优化项提供 —— 它们改的是 MMCSS 音频类任务的分派参数，和「给游戏抢优先级」不是同一件事。
- **禁用全屏优化（FSO）/ 关 MPO**：会连带丢失 Auto HDR 与可变刷新率，或让画面全部改走合成影响录制捕获，代价大于收益。**边界说明**：「关闭游戏 DVR 录制」一项仍会顺带写入全屏优化的兼容开关，那是录制关掉后的附带条件，不构成向用户提供 FSO 开关。
- **高频自动「内存整理」**：反复清工作集只会把数据换回页面文件再读回来。
- **禁用系统服务「越全越好」**：Trim 的批量禁用清单里，商店与同步相关服务保持系统默认。
- **静默/永久禁用 UCPD 驱动来接管默认应用**：该驱动是系统对默认应用选择的防篡改保护层，静默禁用内核驱动 + 计划任务易被安全软件判为风险行为，且 Windows 更新会重新启用。Trim 不提供任何禁用该驱动的入口；批量服务优化项同样不会连带禁用它。改默认应用请直接用 **设置 → 应用 → 默认应用**。
- **MSI 中断模式 / 中断亲和性调优**：无法可靠验证设备是否支持消息信号中断，误开会导致设备失联，不提供。
- **AMD 驱动注册表深度调优**：A 卡用户实机反馈存在副作用，只保留清理类规则。

> 没见过其它「必开优化」出现在 Trim 里，大概率属于上述某类。

规则库与优化目录同理：两条规则库都随版本整体交付、附签名并由门禁对拍，**没有「检查更新并热替换规则」这种入口**。卸载残留规则库确实有一个「在线更新」动作，但它是由你点击触发的显式替换（写入前整包语义校验、失败整包拒绝），不是无人值守的后台自动替换。

## 安全与隐私

- **本地数据优先**：配置、备份、日志不上传。会访问外网的只有你主动触发的动作：网络测速、获取 AI 简介（只上传条目名称与厂商）、运行库修复下载、检查更新、清理规则库在线更新。
- **动系统前先建还原点**：14 项高风险里 9 项无自动还原，备份代替不了还原点。
- **密钥不落日志**：模型密钥以掩码常量回传渲染层，掩码即视为未修改。
- **不静默禁用内核驱动、不绕过安全层**；高危操作一律显式确认。
- **本工具仅供个人测试交流使用，使用风险自负。**
