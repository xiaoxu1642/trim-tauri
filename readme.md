## 它能做什么

**磁盘清理** —— 5 大类共 182 个清理项（清理库 182 条规则全部有效：系统 60 / 应用 69 / 浏览器 36 / 显卡 13 / 特殊 4）。其中 99 条精选自 WinApp2 规则库（源 260915），溯源标 `winapp2-clue`。
**刻意不收录任何 Cookies、浏览器会话、本地站点存储（IndexedDB/LocalStorage）类清理项**——删这些会登出所有网站（2026-10-13 用户裁定全库移除）。
每条都带安装检测（`detect`）：目标软件没装的条目直接不输出；`detect` 里的通配路径会按目录展开后再判存在性。扫描后按风险等级与可释放空间勾选执行，明细可先预览再删，释放空间按删除前后实际差值统计。

**内存清理** —— 按 6 个区域勾选释放内存，含「顽固软件专杀」；调用 Windows 系统接口，与 Mem Reduct 同款原理。

**电脑优化中心** —— 8 个分组共 134 个优化项（SSD 通常可见 130 项），另设「永劫无间优化专项」「隐私自护」两个聚合面板（侧表驱动，面板成员从主分类列表整组移入、不重复展示）。
单项执行或勾选一批执行；每项都有详情弹窗、风险等级、预期效果与**可核对的还原入口**。
数据层声明含 pwsh 步骤的 29 项 / 31 步，但执行时 38/40 步由 Rust 原生引擎完成（注册表/服务/计划任务/设备禁用），真正起 PowerShell 5.1 的只剩 2 步（两个 AppX 移除项）。

**启动项管理** —— 扫描注册表 / 启动文件夹 / 计划任务，启停与系统「任务管理器」同轨（随时可逆），删除前自动备份。
注册表里写着的路径已经不存在时，该项标为「待确认」并原样显示那个路径，出口是查看详情、删除启动项、打开系统自带的 Windows 安全中心——只报事实，不替你判定它是不是恶意。

**右键菜单管理** —— 按 15 类扫描，但**按软件成列**：一列一个程序，列头是它的真实图标与「N 项 · M 个位置」，位置与状态标签直接跟在名称后。
归属由程序文件的版本信息判定，靠推断得来的会标注依据，判不出的集中到「未识别」列而不是硬猜一个名字；勾选即启用、取消即禁用。

**应用卸载与残留** —— 调起原厂卸载器（静默命令由后端准入闸裁决，不信任界面回传的命令文本）；卸载成功后自动弹出**「应用卸载残留扫描」窗口**，只展示**该应用**的四类残留：服务残留 / 驱动残留 / 注册表残留 / 文件·文件夹残留，每类各自给依据。
文件与目录**回收站优先**（失败不改成永久删除）；注册表先 `export` 备份再删、备份失败该项不动。服务与驱动两类只报「`ImagePath` 指向的二进制已不存在」且确属该应用的键；删除要过八道现读判据（落点已失踪、不在系统目录、非内核驱动、非 boot/system 启动、无依赖声明、不在反作弊名单等）并先整键导出 `.reg` 备份，驱动类通常会被挡下（候选仍列出供你判断）。受保护与未过判据的一律只说明为什么，勾选后仍要逐项确认。

**占用查询**（0.8.3 新增）—— 任意文件或目录一键查「被谁占用」：走系统 Restart Manager（与清理前占用检测同源），列出占用进程与应用名；非系统关键进程可一键结束（红色二次确认）。

**系统维护与 Windows 设置** —— SFC / DISM / Windows 更新组件重置 / 音频服务 / 搜索索引 / DNS 刷新 / 网络栈重置等维护任务；**Windows 设置页**收拢电源计划（三档切换 / 新建克隆 / 逐设置编辑，改前自动备份、可还原）、虚拟内存读写（写前备份）与 Windows 更新三态（彻底禁用 / 恢复自动 / 暂停到指定日期）。

**运行库、测速与网络** —— 检测 VC++ / .NET Framework / DirectX 安装状态，缺失时经微软官方直链（SHA-256 校验）补装；磁盘测速为原生 OVERLAPPED 异步 I/O，块大小、队列深度、线程数、时长均可调；网络测速走 SpeedTest.cn 或中国科大节点；6 项只读诊断（网卡 / IP / DHCP / DNS / 代理 / 连通性），异常项给证据与修复建议；常驻实时网速显示上下行速度与丢包率，可录制并生成折线图报告。

**外设调优、还原与备份** —— 优化中心内「更多调优项」以应用内弹窗提供处理器调度、鼠标事件缓冲两组深度调优，每档配「数值解释」说明这个数到底控制什么；键盘队列深度与端口路由已并入优化中心的键盘项统一管理。
系统还原点：查看各磁盘保护状态，一键为所有已开启保护的磁盘创建还原点。备份还原：各类注册表 / 文件备份统一管理，值级回读校验后才算还原成功。

**联网 AI 简介（可选）** —— 启动项 / 右键 / 内存清理的条目详情可主动获取 AI 简介；不联网时用内置本地简介。

## 安装

在 [Releases](../../releases) 下载 `Trim_<版本>_x64-setup.exe` 双击安装，或下载 `Trim_<版本>_x64-portable.zip` 解压后直接运行 `Trim.exe`。

- **安装版**：桌面快捷方式 + 卸载项，更新走应用内「检查更新」。
- **便携版**：解压到有写入权限的目录即可，不创建快捷方式与卸载项；升级时先退出旧进程再覆盖解压。

> 便携版默认使用 `%APPDATA%` 下的数据目录。在 `Trim.exe` 同目录新建空文件 `Trim.portable` 可切换为便携模式（数据改存程序目录的 `data` 子文件夹），删除该标记文件即恢复。

系统要求 Windows 11。多数功能需要**管理员权限**（写 HKLM、改服务），未提权时界面会明确提示，可回主窗口以管理员身份重启。

## 使用

### 优化项怎么改

点任意优化项弹出详情窗，里面有：执行步骤、风险等级、预期效果、优缺点、可还原入口。确认后点 **立即执行**。

- **已优化的项**整行灰态，点击可还原。本机有值级备份的按备份逐值还原，没有的置灰并说明原因——不会给一个点了必然失败的按钮。
- **批量执行**前会整批预检（权限 / 高危确认 / 本机可执行性），被拦项先告知再执行，不会「第 5 项失败时前 4 项已落盘」。
- **写后回读**：执行与还原都会重新读注册表核对，不符即如实报错并保留备份（fail-closed）。
- 134 个优化项按 8 个分组显示（另有「隐私自护」面板收拢 21 个隐私/遥测项），134 项里有 9 项高风险，其中 **3 项执行后无自动还原**（其余 6 项支持一键还原）。凡是动服务、驱动、注册表、启动参数的，**先建系统还原点**。

### 删除类操作

- 除「常规清理项」固定永久删之外，一律**回收站优先**，且删除前过受保护目录校验；
- **清空回收站是唯一不经 Trim 备份的不可逆动作**：它走系统 Shell 接口、执行前先把条目数与体积摆出来，再弹红色高危确认；清空后不经过 Trim 的任何备份，条目默认不勾选；
- 启动项删除前自动备份注册表项；右键菜单项只提供可逆的启用/禁用（不提供删除），需要删除时请自行用注册表编辑器，桌面既有的「右键菜单备份_*」目录可手工导入恢复；
- 高危操作弹红色二次确认，确认框里写明具体后果与影响范围。

### 原理

```
┌──────────────┐   IPC 通道白名单    ┌─────────────────────┐
│  渲染进程     │ ──────────────────> │  Rust 命令层         │
│  零框架       │ <────────────────── │  guard 来源校验       │
│  原生 HTML/CSS │   JSON 回执         │  白名单 / 取值校验    │
└──────────────┘                     └──────────┬──────────┘
                                                 │
                        ┌────────────────────────┼────────────────────────┐
                        ▼                        ▼                        ▼
              Win32 / WinHTTP 原生        reg.exe / 签名规则库        应用私有数据目录
              （服务 / 注册表 / HTTP）      （备份 / 装载前验签）      （配置 / 备份 / 日志）
```

- **执行前先记账**：写不进状态文件就不改系统（fail-closed）。
- **每条命令都有来源校验**：主窗专属通道与只读通道分档，多窗口应用不允许裸注册命令。
- **规则库与优化目录随版本交付并签名**，装载前验签；没有「后台定时热替换规则」这种入口。
- **数据留在本机**：配置、日志、备份全在 `%APPDATA%\com.xiaoxu.trim`，便携模式改存程序目录。

## 安全与隐私

- **本地数据优先**：配置、备份、日志不上传。会访问外网的只有你主动触发的动作：网络测速、获取 AI 简介（只上传条目名称与厂商）、运行库修复下载、检查更新。
- **动系统前先建还原点**：9 项高风险里 3 项无自动还原，备份代替不了还原点。
- **密钥不落日志**：模型密钥以掩码常量回传渲染层，掩码即视为未修改。
- **不静默禁用内核驱动、不绕过安全层**；高危操作一律显式确认。
- **本工具仅供个人测试交流使用，使用风险自负。**
